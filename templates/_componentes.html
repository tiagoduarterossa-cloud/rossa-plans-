{# Peças reutilizáveis. Um "macro" do Jinja funciona como uma função: escreves {{ icone('lixo') }} e ele põe ali o desenho do caixote do lixo. Sem categoria (None) fica cinzento. #} {% macro classe_cor(cor) -%} {{ "cor-%d" % cor if cor is not none else "cor-nenhuma" }} {%- endmacro %} {# Etiqueta com a bolinha de cor da categoria #} {% macro etiqueta(nome, cor) -%} {{ nome or "Sem categoria" }} {%- endmacro %} {# Lista para escolher a categoria, com "Sem categoria" no início e "Nova categoria..." no fim. Quando escolhes "Nova categoria...", o JavaScript mostra a caixa para escreveres o nome. #} {% macro campo_categoria(categorias, selecionada) -%} {%- endmacro %} {# Fila de bolinhas para escolher a cor.
